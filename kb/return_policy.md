# Return Policy

## Return window
Customers may request a return within 14 calendar days after delivery. A human reviewer confirms whether the request is within the window.

## Item condition
Items should be unused and include original packaging when available. A reviewer decides whether an item's condition qualifies.

## Starting a request
Contact support with the order number and reason for return. Sending a request does not itself approve a return.

## Review
A support reviewer checks eligibility and explains any next steps before a return is sent.
